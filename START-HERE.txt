MODLOCKET - PERSONAL BUILD 09 - NO BATTLEYE

1. Extract this ZIP into its own folder.
2. Close the old ModLocket window.
3. Run Start-ModLocket.cmd from THIS folder. The app should show
   4.0.0-personal.9-nobe. An old EXE does not pick up these source changes.

RESTORE MISSING MODS
- Keep ARK closed. Click RESTORE MISSING MODS.
- Review the list, then click Restore listed missing mods.
- Missing files are restored from the selected full backup. Missing ARK
  installation records are inserted from that same backup.
- Existing records, enabled settings, unrelated mods and newer installed
  versions are preserved. A mod with conflicting files is skipped.
- Existing OutOfDate records can have missing files recovered without
  clearing their status. Pending entries are left for ARK to finish.
- Recovery finishes without launching ARK. You can launch afterward.
- This needs a full backup containing the mod files and records. A small
  saved mod list alone cannot reinstall missing files.
- This restores the SAVED version, not a newer release. ARK and servers
  may still require an update or ownership verification.
- Mods deliberately removed since the backup may also be offered. Review
  the list before restoring. Cancel if the listed recovery is unwanted.

LAUNCH ANYWAY
- Click Launch anyway - allow outdated mods below the restore buttons,
  or Launch anyway in the update results window.
- This opens ARK through Steam without ModLocket's version/file checks.
- It does not delete, disable, update or rewrite your installed mods.
- It does not force ARK or a server to accept an older version.
- An active or interrupted file-writing operation must finish first.
  Click RESTORE MISSING MODS to resume an interrupted recovery.

BACKUPS AND UPDATES
- BACKUP saves the files and records of the currently installed collection.
- MANAGE BACKUPS lets you select an existing full snapshot.
- Keep existing backups while testing this build.
- CHECK FOR UPDATES still uses official CurseForge access. Restricted
  downloads and premium ownership checks are not bypassed.

NO BATTLEYE LAUNCH PATCH
- Every launch button explicitly requests Steam's No BattlEye option.
- Use this for single-player or servers that do not require BattlEye.
- Close any old ModLocket window and run Start-ModLocket.cmd here.
- Existing standalone EXEs do not pick up this source patch.
