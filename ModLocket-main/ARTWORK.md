# Footer ornament

Footer-Snake.png is a transparent PNG produced with the built-in image tool
from the approved Moonlit ModLocket interface mockup. The PNG is copied intact.
The footer renders its occupied area and mirrors the second instance at drawing
time so both snakes face the central caption. Original logo bytes are unchanged.

Generation prompt:
Use case: background-extraction. Project asset for the ModLocket desktop app.
The supplied image is the approved UI reference, NOT a UI to redesign.
Extract/reproduce ONLY the tiny lavender-and-silver snake ornament beside the
bottom footer text on the LEFT side: a single very slender gently waving snake,
tapering tail on the LEFT and a small elegant head facing RIGHT, a visible tiny
dark eye, metallic lavender body with pale silver highlights. Match that specific
little footer snake, not the large circular logo snake. Produce one isolated
horizontal snake ornament on a truly transparent alpha background. Wide 3:1
canvas, ornament stretches across about 85 percent of canvas width; small
vertical extent. No lines, no diamonds, no frame, no letters, no UI, no logos,
no other objects. Preserve the refined understated silver-lavender style.
Output a clean transparent PNG suitable for rendering about 80 pixels wide.
