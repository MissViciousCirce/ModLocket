# Approved UI changes implemented through iteration 03

BACKUP is the permanent label for first setup and later updates. No setup info
note is shown. RESTORE MISSING FILES replaces Verify + Repair; its adjacent
information icon explains that it can take a few minutes. Hover shows this explanation; click or explicit keyboard
activation opens a dark help dialog. Focus alone must never open the tooltip. Close Anyway is shown only during an attempt
to close active work, never as a permanent part of the main interface.

Application-owned backup management/review/confirmation/cancellation windows
use the dark Status-area palette. Use the approved original ViciousCirceLogo.png
directly. Footer wording: Protecting your purchased skins, custom mods, and tiny
digital dinosaurs. Check for Updates is the requested label, with a subtitle
identifying the local and published-version comparison in preview 04. The new
connection and comparison dialogs use the same dark theme.

The generated mockup is a visual reference. First Windows screenshots should
inform spacing, font/DPI and decorative refinements without changing engine
behavior. Preserve the under-30-second quick-launch target and progress/elapsed/
last-progress information. Do not confuse a moving indicator with proof of
healthy work. Existing 70 GiB backups must survive app UI upgrades.

Iteration 02 addresses the first Windows feedback: keep the log rectangular
and inset inside its rounded frame, put the info control above the action
artwork, and restore paired inward-facing lavender snakes beside the footer.
The tooltip must disappear on pointer leave, deactivation or an active action.

Iteration 03 centers the Restore caption between equal-width arrow and info
columns. The info control is circular, follows the underlying button gradient
and uses a circular focus cue. The user withdrew the hair-edit request; keep
the original logo and hair highlights exactly as they were.

Restore the idle mint READY, SURVIVOR badge. Active work, launch handoff and
errors must still show their actual state rather than this idle greeting.
